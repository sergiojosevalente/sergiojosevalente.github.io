Moxtel

Privacy Policy

Last updated: 6 November 2026

Moxtel is a free terminal and file-transfer application for Windows, made by Sergio Jose Valente Da Cruz ("the author"). This policy explains what happens to your information when you use Moxtel, whether you got it from GitHub, winget or the Microsoft Store.

Summary

  • Moxtel does not collect, sell or share personal data. It has no account, no analytics, no advertising and no telemetry.
  • Everything you save stays on your computer, encrypted.
  • Moxtel connects only to the servers you choose to open, and — only if you ask it to — to GitHub to look for updates.

Information stored on your computer

WhatWhere and how
Saved sessions, folders, tunnels, macros, transfer profiles and settingsYour Windows user's application data folder, encrypted with Windows DPAPI for your account.
Passwords, key passphrases and access keys you choose to saveAn encrypted vault (AES-256-GCM, key derived from your master password with Argon2id).
Command history for suggestions (can be turned off)Encrypted with DPAPI; commands that look like they contain passwords or tokens are never stored.
Auto Transfer run historyEncrypted with DPAPI; can be deleted in the app.
Terminal logs and recordings (only if you turn them on)Normal files in the folder you choose.

The author never receives any of this information. Uninstalling Moxtel offers to delete it.

Network connections

  • Servers you open (SSH, RDP, VNC, FTP, SFTP, S3, Telnet, Mosh and others): Moxtel sends the data needed for those connections, such as your user name and password, only to that server.
  • E-mail reports (optional): if you set up an SMTP server for Auto Transfer reports, reports are sent through that server to the addresses you enter.
  • Network tools: ping, traceroute, port scans and certificate checks contact only the host you enter.
  • Updates: the GitHub and winget versions contact api.github.com and github.com when you choose Check for updates (or turn on the check at startup). GitHub receives the usual information of any web request, such as your IP address, under GitHub's privacy statement. The Microsoft Store version does not do this; the Store handles its updates.
  • Links you click (for example to this website) open in your web browser.

Microsoft Store

If you install Moxtel from the Microsoft Store, Microsoft processes data related to the download, installation and updates under the Microsoft Privacy Statement. Moxtel itself does not add any data collection.

Children

Moxtel is a tool for IT work and is not directed at children. It does not knowingly collect information from anyone.

Changes

If this policy changes, the new version will be published on this page with a new date.

Contact

Questions about privacy: sergiojosevalente@gmail.com, or open an issue at github.com/sergiojosevalente/moxtel.
